# Telegram-бот «Спорт и питание»

Бот генерирует посты для Telegram-канала о спорте и правильном питании:
текст через DeepSeek, картинку через бесплатный Pollinations, независимую
проверку перед публикацией — вторым запросом к DeepSeek. Умеет публиковать
по расписанию.

## Что умеет

- **/post** — пост на очередную тему из ротации (тренировка → питание → восстановление → мифы → микрошаг).
- **/topic &lt;тема&gt;** — пост на ваш запрос.
- **/help**, **/start** — справка и приветствие.
- **Автопостинг** — публикует пост в канал по расписанию; в этом проекте выставлено 07:00 и 19:00 по Москве.
- К каждому посту: картинка (1024×1024), проверка на логику, факты, опасные советы и опечатки.
- Если проверка нашла проблему — бот автоматически переписывает пост и проверяет его заново.
- Кнопка «Опубликовать в канал» под проверкой — ручная публикация из личного чата.

## Доступ только для владельца

Все команды и кнопки закрыты проверкой `OwnerOnlyMiddleware`: пост может
сгенерировать и опубликовать только владелец бота. Чужим бот отвечает
«Это приватный бот» и пишет их id в лог.

Если `OWNER_ID` не задан, бот отказывает всем — так безопаснее, чем открытый
доступ. Чтобы узнать свой id: напишите боту любое сообщение, в логе появится
строка `Доступ запрещён: id=…`, а сам бот ответит вашим id в сообщении.
Впишите его в `OWNER_ID` (в панели хостинга) и перезапустите.

## Подписка

Пробный период — `TRIAL_DAYS` (7) дней, один раз на пользователя. Дальше
доступ на `SUBSCRIPTION_DAYS` (30) дней за `SUBSCRIPTION_PRICE_STARS` (250)
звёзд Telegram.

Цифровые товары в Telegram продаются только за Stars: `currency="XTR"`,
`provider_token` пустой. Пользователь платит обычной картой, пополняя звёзды
внутри Telegram.

`SALES_ENABLED=false` по умолчанию: счёт не выставляется, пока платные
функции не готовы. Включите флаг, когда будет что продавать.

Состояние хранится в SQLite (`DB_PATH`, по умолчанию `fitbot.db`):
таблицы `subscriptions` и `payments`. Продление идемпотентно по
`telegram_payment_charge_id` — повторный `successful_payment` не удвоит срок.

## Ручная оплата переводом

Помимо Stars доступна оплата переводом: `/sub` → «Оформить на 30 дней».
Бот создаёт заявку с уникальной суммой (349.07, 349.08 …), чтобы платёж
можно было найти в выписке по копейкам.

- `PAYMENT_MODE=qr` — кнопка «Оплатить по СБП» со ссылкой `PAYMENT_LINK`
  (её даёт «Мой налог»); файл `PAYMENT_QR_PATH` необязателен и нужен только
  если хотите показывать картинку QR;
- `PAYMENT_MODE=card` — номер карты (`CARD_NUMBER`) и получатель (`CARD_HOLDER`).

Заявка живёт `ORDER_TTL_MINUTES` (60) минут. Пользователь нажимает
«Я оплатил», владельцу приходит карточка с кнопками «Подтвердить/Отклонить»,
после подтверждения подписка продлевается через `subs.add_paid_days`.
Повторное подтверждение безопасно: срок не удваивается.

Кнопка «Оформить» появляется только если есть QR-файл или ссылка (для card —
номер карты), чтобы случайно не продавать в пустоту.

## Анкета и план тренировок

Кнопка «📋 Мой план» (или `/plan`) запускает анкету из 8 шагов:
цель → опыт → дни в неделю → минуты на тренировку → инвентарь →
ограничения по здоровью → рост → вес. Ответы хранятся в таблице `profiles`
(`profiles.py`).

Ограничения отмечаются кнопками-переключателями. При выборе исключаются
упражнения с нагрузкой на проблемную зону:

| Ограничение | Что убираем из плана |
|---|---|
| Колени | приседы (штанга, гантель, гоблет, свой вес), выпады, жим ногами, гакк, скакалка |
| Спина, поясница | становая, румынская, тяга с плинтов, наклоны со штангой, тяга в наклоне, «супермен» |
| Плечи | жимы над головой, подъёмы и разведения, тяга к подбородку, брусья, жим на наклонной |
| Сердце, давление | план остаётся, но добавляется предупреждение: нагрузку согласует врач |

Исключения заданы списками slug в `planner.EXCLUDE_BY_LIMIT` — проще
проверять и дополнять, чем угадывать по названию. Те же правила применяются
в каталоге: упражнение, которое не рекомендовано при ограничениях, помечается
в списке «⚠️», а в карточке сверху появляется предупреждение. Справочник и
план не противоречат друг другу. Если после исключений
группа пустеет, день получается короче, но без дублей и без «запрещённых»
упражнений.

План строит `planner.py` — **детерминированно, без LLM**: одинаковые ответы
дают одинаковый план. Модель бы придумала несуществующие упражнения, а здесь
выбор идёт из библиотеки с фильтрами:

- уровень опыта ограничивает сложность (новичок не получает «продвинутые»);
- инвентарь ограничивает оборудование (для «только свой вес» — без штанги);
- дни определяют сплит: 2–3 — всё тело, 4 — верх/низ, 5 — жим/тяга/ноги;
- минуты определяют число упражнений в дне (20 → 4, 60 → 7);
- цель задаёт схему: масса 4×6–10, рельеф 3×10–15, тонус 3×12–15.

Одно упражнение не повторяется внутри дня: если группа исчерпана, день
получается короче, но без дублей.

## Библиотека упражнений

55 упражнений в `exercises.json` + по два фото в `media/exercises/<slug>/`.
Исходные фото — из [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
(лицензия Unlicense, public domain). Русские названия, подсказки, частые ошибки
и примечания по безопасности написаны заново.

Поле `free: true` — карточка доступна без подписки (17 из 55). Бесплатные есть
во всех шести группах, чтобы можно было попробовать любое направление.

Группы: грудь 7, спина 11, ноги 13, плечи 7, руки 7, пресс 10. Длинные группы
показываются страницами по 6 карточек (кнопки ← → и счётчик вида 1/3).

Каталог: кнопка «🏋️ Упражнения» → группа мышц → карточка. Карточка уходит
альбомом из двух кадров (старт/финиш), подпись — до 1024 символов.
После первой отправки `file_id` кэшируются в таблице `media_cache`,
чтобы не загружать файлы повторно.

Пополнить библиотеку: добавить запись в `exercises.json`, выполнить
`python import_exercises.py` (докачает только отсутствующие картинки).

## Кнопки меню

Внизу чата постоянная клавиатура: «💳 Подписка» и «ℹ️ Помощь» — для всех.
Владельцу дополнительно видны «📝 Новый пост», «✍️ Пост на тему», «💾 Бэкап».
Кнопки дублируют команды, ввод текста не обязателен. Меню приходит по /start
или /help; админские кнопки не видны посторонним.

## Бэкап базы

На бесплатном тарифе база лежит внутри контейнера и стирается при Redeploy,
поэтому бот сам отправляет копию владельцу:

- после каждой подтверждённой оплаты (обычный платёж и Stars);
- раз в сутки фоновой задачей;
- вручную командой `/backup` (присылает файл `.db` в чат).

Копии также складываются в `BACKUP_DIR` (по умолчанию `backups/`),
хранится последние `BACKUP_KEEP` (14) штук.

Восстановление: перешлите боту файл `.db` — бот проверит заголовок SQLite,
сделает `PRAGMA integrity_check`, сохранит текущую базу как
`fitbot.db.before-restore.db` и подменит файл. После восстановления
перезапустите бота.

Если при старте база не найдена, владелец получает предупреждение в личку.

## Структура проекта

~~~
Deepseek tg bot/

├── ai_client.py      # DeepSeek: генерация, проверка, исправление; parse_sections

## Требования

- Python 3.10 или новее
- Аккаунт Telegram и бот у @BotFather
- API-ключ DeepSeek
- Канал, где бот — администратор (для автопостинга)

## Шаг 1. Получить токен бота

1. Откройте @BotFather в Telegram.
2. Отправьте /newbot, придумайте имя и username (должен заканчиваться на bot).
3. Скопируйте токен вида 123456789:AA... — это TELEGRAM_TOKEN.

## Шаг 2. Получить ключ DeepSeek

1. Зайдите на platform.deepseek.com и войдите в аккаунт.
2. Пополните баланс (API платный, но дешёвый) — без баланса запросы вернут ошибку 402.
3. Раздел «API keys» → «Create new API key» → скопируйте ключ вида sk-...
   Ключ показывается один раз, сохраните его.

## Шаг 3. Установить зависимости

~~~
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt
~~~

## Шаг 4. Создать .env

~~~
copy .env.example .env          # Windows
# cp .env.example .env          # Linux/macOS
~~~

Заполните минимум три переменные:

- TELEGRAM_TOKEN — токен от @BotFather
- DEEPSEEK_API_KEY — ключ DeepSeek
- CHANNEL_ID — канал для автопостинга

CHANNEL_ID можно указать как @username канала или как числовой id вида
-1001234567890. Числовой id надёжнее: username можно сменить.

## Шаг 5. Добавить бота в канал

1. Откройте канал → «Управление» → «Администраторы» → «Добавить администратора».
2. Найдите бота по username и добавьте.
3. Достаточно прав «Публикация сообщений» (для фото и текста больше ничего не нужно).
4. Без прав администратора бот получит ошибку 403 при отправке в канал.

Если планируете брать числовой id: перешлите любой пост канала боту @username_to_id_bot
или посмотрите id в ссылке веб-версии канала.

## Шаг 6. Запустить бота

~~~
python bot.py
~~~

В логах должно появиться:

~~~
INFO | aiogram.event | Update id=... is handled
INFO | bot | Бот запущен, жду команды
~~~

Напишите боту /start, затем /post.

## Настройки (.env)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| TELEGRAM_TOKEN | — (обязательно) | Токен бота от @BotFather |
| OWNER_ID | пусто | Telegram id владельца (можно несколько через запятую); пусто = бот откажет всем |
| DEEPSEEK_API_KEY | — (обязательно) | Ключ DeepSeek |
| CHANNEL_ID | пусто | Канал для публикаций; без него автопостинг и кнопка выключены |
| DEEPSEEK_MODEL | deepseek-chat | Модель DeepSeek |
| DEEPSEEK_BASE_URL | https://api.deepseek.com | Эндпоинт (OpenAI-совместимый) |
| REQUEST_TIMEOUT | 90 | Таймаут запроса к DeepSeek, секунды |
| AUTOPOST_ENABLED | true | Включён ли автопостинг |
| POST_INTERVAL_HOURS | 6 | Публикация каждые N часов (0.25 = 15 минут) |
| POST_TIMES | 07:00,19:00 | Расписание по времени (через запятую); приоритетнее POST_INTERVAL_HOURS |
| TIMEZONE | Europe/Moscow | Часовой пояс расписания |
| IMAGE_WIDTH / IMAGE_HEIGHT | 1024 / 1024 | Размер картинки |
| IMAGE_TIMEOUT | 90 | Таймаут генерации картинки, секунды |
| POST_MIN_CHARS / POST_MAX_CHARS | 250 / 400 | Границы объёма поста |
| LOG_LEVEL | INFO | Уровень логирования |

## Как работает пайплайн

1. **Генерация.** DeepSeek получает системный промт (роль, стиль, запреты) и тему.
   Ответ строго из трёх блоков: [ПОСТ], [ИДЕЯ ДЛЯ КАРТИНКИ] (промт на английском), [ПРОВЕРКА].
2. **Разбор.** parse_sections ищет заголовки в квадратных скобках, понимает варианты
   написания, markdown-обвязку и пропущенные секции. Если блока [ПОСТ] нет — ошибка.
3. **Объём.** Если пост вне 250–400 символов, модель переписывает его один раз.
4. **Проверка.** Второй запрос с промтом фактчекера возвращает «СТАТУС: OK» или
   «СТАТУС: ПРОБЛЕМА» и список замечаний.
5. **Исправление.** При проблеме модель переписывает пост, затем он проверяется ещё раз.
6. **Картинка.** Промт уходит на image.pollinations.ai, файл скачивается в отдельном
   потоке параллельно с проверкой. При сбое пост уходит без картинки.
7. **Отправка.** Картинка с подписью-постом, следом сообщение «Проверка перед публикацией».

При автопостинге в канал уходит только пост с картинкой; проверка пишется в лог.
Если проверка нашла серьёзные проблемы и автоисправление не помогло — публикация
пропускается, чтобы не выложить опасный совет.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| RuntimeError про переменные окружения | Нет .env или пустые TELEGRAM_TOKEN / DEEPSEEK_API_KEY |
| Ошибка 401 от DeepSeek | Неверный DEEPSEEK_API_KEY |
| Ошибка 402 от DeepSeek | Нулевой баланс на platform.deepseek.com |
| Ошибка 403 при публикации | Бот не админ канала или указан чужой CHANNEL_ID |
| «Картинку получить не удалось» | Pollinations перегружен; пост уйдёт без фото, повторите позже |
| Пост длиннее 400 символов | Модель не уложилась; уменьшите POST_MAX_CHARS или повторите /post |
| Автопостинг молчит | Проверьте AUTOPOST_ENABLED, CHANNEL_ID и строку «Планировщик настроен» в логах |

## Ограничения и честные предупреждения

- Pollinations — бесплатный сервис без SLA: иногда отвечает медленно или отдаёт ошибку.
  Бот это переживает, но картинка может не прийти.
- DeepSeek может ошибаться. Автопроверка снижает риск, но не заменяет человека:
  перед публикацией просматривайте пост и сообщение с проверкой.
- Бот не даёт медицинских рекомендаций: темы про травмы, болезни и лекарства
  сознательно не поддерживаются промтом.
- Контент генерируется моделью и может совпадать с чужими текстами — при серьёзном
  канале добавьте ручную редактуру.
